# QA 테스트케이스 — 성경 쓰기 (절 작성)

> 작성: 2026-05-21

## P0 승인 기준
타이핑 정상 플로우 + 진척도 저장 확인 + 완료 UX

---

## TC-101 · 타이핑 모드 정상 완료
- **입력**: 절 입력창에 말씀 입력 → 완료 확인 탭
- **기대**: 토스트 메시지 표시 → 1.8초 후 다음 절로 이동
- **확인**: Supabase verse_progress에 행 생성 (fully_complete_at NOT NULL)

## TC-102 · 타이핑 모드 — 3자 미만 입력
- **입력**: 1~2자 입력 후 완료 확인
- **기대**: "입력이 너무 짧아요" Alert, 완료 처리 안 됨

## TC-103 · 문지르기 모드 — 줄 단위 완료
- **입력**: 각 줄 탭 → 모든 줄 탭
- **기대**: 탭한 줄 골드 하이라이트 → 전체 완료 시 토스트

## TC-104 · 장 전체 완료 팝업
- **조건**: 한 장의 모든 절 완료
- **기대**: 장 완료 팝업 표시 (emoji_events 아이콘, "n장으로" 버튼)

## TC-105 · 이미 완료된 절 표시
- **조건**: 특정 절 완료 후 같은 화면 재진입
- **기대**: 절 네비에 ✓ 표시 + 골드 배경

## TC-106 · 언어 전환 (한글 → ENG)
- **입력**: ENG 탭 선택
- **기대**: 해당 절 텍스트가 KJV 영문으로 교체
- **확인**: 완료 처리 시 language='en'으로 저장

## TC-107 · 성경 데이터 로딩 실패
- **조건**: 인터넷 연결 없이 캐시 없는 장 진입
- **기대**: "말씀을 불러오지 못했습니다" + 다시 시도 버튼

## TC-108 · 성경 데이터 캐싱
- **조건**: 한 번 로드된 장 → 오프라인 상태에서 재진입
- **기대**: API 호출 없이 정상 표시 (AsyncStorage 캐시)

## TC-109 · 절 그리드 — 31절 이상
- **조건**: 창세기 1장 (31절) 진입
- **기대**: 모든 31개 절 그리드에 표시 (flexWrap)

## TC-110 · 진척도 홈 화면 반영
- **조건**: 절 완료 후 홈 탭으로 이동
- **기대**: 해당 책 카드의 진척도 바 업데이트

## 미구현 (추후 테스트)
- OCR 모드 (사진 촬영 → Naver Clova)
- STT 모드 (음성 녹음 → Whisper)
- 스크롤 vs 문지르기 제스처 충돌
- 실시간 피드백 지연 ≤ 16ms
