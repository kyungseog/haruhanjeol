## 2. 핵심 기능 — 4가지 입력 방식

| 방식 | 설명 | 개발 상태 |
|------|------|----------|
| ⌨️ 타이핑 | 키보드로 직접 입력 | ✅ 완료 |
| 📸 사진 | 종이에 손으로 쓴 것을 촬영 → OCR | 🔄 미구현 |
| 🎙 음성 | 성경 구절을 읽어서 녹음 → STT | 🔄 미구현 |
| 👆 문지르기 | 화면에 표시된 절 위를 손가락으로 문질러 완료 | ✅ 기본 구현 |

### 절별 언어 전환
- 각 절을 한글 또는 영문으로 선택해 작성 가능
- 절 작성 화면 상단에 **한글 ↔ ENG 토글**
- 기본값: 한글

## 3. 완료 구조

### 완료 단위
- **절(verse) 단위**로 완료 처리
- 장(chapter) 전체 완료 시 → 파티클 애니메이션 + 클리어 카드 팝업

### 진척도 UI (3단계)
1. **홈 화면**: 구약/신약 66권 카드. 완료율에 따라 색상 (회색 → 골드)
2. **책 선택 후**: 장(chapter) 그리드. 완료=골드, 진행중=연골드, 미시작=회색
3. **장 선택 후**: 절 그리드 네비 + 말씀 카드

### 완료 시 UX
- **절 완료 (장 미완)**: 토스트 메시지 → 1.8초 후 자동으로 다음 절
- **장 전체 완료**: 팝업 카드 → "목록으로" / "n장으로" 버튼

## 4. 문지르기 인터랙션 상세

### 완료 판정 알고리즘
```
완료(complete) = (커버리지 ≥ 85%) AND (소요 시간 ≥ 0.6초) AND (스트로크 누적 길이 ≥ 텍스트 영역 폭 × 줄 수 × 1.2)
부분(partial)  = (커버리지 ≥ 30% AND < 85%)
무효(void)    = (커버리지 < 30%) OR (소요 시간 < 0.6초)
```

### 서버 설정값 (Remote Config)
```
gesture.completion.coverage_threshold = 0.85
gesture.completion.min_duration_ms = 600
gesture.stroke_width_dp = 32
gesture.idle_timeout_ms = 1500
```

### 데이터 모델
```json
verse_progress: {
  user_id, book_id, chapter, verse,
  language: "ko" | "en",
  total_lines, completed_lines: [int],
  fully_complete_at, rub_count, last_rub_at, last_updated
}
```

## 5. OCR / STT 정확도 기준

### 텍스트 정규화 (비교 전 양쪽 적용)
- 유니코드 NFC 통일, 문장부호 제거, 공백 정규화, 절/장 번호 토큰 제거

### 임계치 매트릭스

#### 성인 계정
| 입력 방식 | 자동 통과 | 사용자 확인 | 거절 |
|----------|---------|------------|------|
| 타이핑 | ≥ 98% | 95~98% | < 95% |
| OCR (인쇄) | ≥ 92% | 82~92% | < 82% |
| OCR (필기) | ≥ 88% | 75~88% | < 75% |
| STT (조용) | ≥ 92% | 85~92% | < 85% |
| STT (소음) | ≥ 88% | 78~88% | < 78% |

#### 어린이 계정
| 입력 방식 | 자동 통과 | 사용자 확인 | 거절 |

## 11. QA 기준 (MVP 출시 게이팅)

### 어린이 사용성
- 고학년(4~6학년) 6/6 완주 (보호자 도움 없이)

### 문지르기 게이팅
- P0 완료 판정 케이스 100% 통과
- 스크롤 vs 문지르기 오동작 = 0건
- 실시간 피드백 지연 ≤ 16ms
