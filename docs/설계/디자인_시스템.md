## 2. 타이포그래피 — Pretendard

| 용도 | Weight | 스타일 |
|------|--------|--------|
| 앱 이름 | Bold | 30~32px |
| 화면 제목 | Bold | 17~18px |
| 섹션 제목 | Bold | 13px, letterSpacing 0.5 |
| 본문 | Regular | 15~17px, lineHeight 26~30 |
| 버튼 | Bold / SemiBold | 14~16px |
| 캡션 | Regular / Medium | 10~12px |

> ⚠️ React Native에서 `fontWeight`와 `fontFamily`를 함께 쓰면 충돌.
> Pretendard에서는 반드시 `fontFamily`로 굵기 표현 (fontWeight 사용 금지).

## 4. 앱 아이콘

- **형태**: 비타민 캡슐 (좌: 골드 그라데이션, 우: 크림)
- **구현**: SVG (react-native-svg)
- **파일**: `components/icons/AppIcon.tsx`
- **배경**: 라이트 `#FFF8EC` / 다크 `#2A2A3E`

## 5. 문지르기 비주얼

- **스타일**: 형광펜 칠하기
- **색상**: `rgba(245,166,35,0.18)` → 완료 시 `rgba(245,166,35,0.35)`
- **줄 단위**: 각 줄을 탭으로 완료 처리
- **성능**: React Native Reanimated (16ms 이내)

## 6. 레이아웃 컨벤션

- 화면 수평 패딩: 20px
- 카드 border-radius: 16px (소형 10px)
- 카드 border: 1~1.5px `#EFEFEF`
- 버튼 높이: 52~54px, border-radius: 14px
- 탭바 높이: 72px, paddingBottom: 12px
