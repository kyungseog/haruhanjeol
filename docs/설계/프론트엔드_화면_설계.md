# 프론트엔드 화면 설계 — 하루한절

> 업데이트: 2026-05-21

## 1. 화면 구조 (expo-router 기반)

```
app/
├── (auth)/
│   └── login.tsx          # 로그인/회원가입 ✅
├── (tabs)/
│   ├── _layout.tsx        # 탭 네비게이션 ✅
│   ├── index.tsx          # 홈 (성경 목록) ✅
│   ├── group.tsx          # 모임 ✅ (UI, mock 데이터)
│   └── settings.tsx       # 설정 ✅
├── bible/
│   ├── [bookId].tsx       # 장 목록 ✅
│   └── write.tsx          # 절 작성 ✅
└── _layout.tsx            # 루트 레이아웃 + 인증 라우팅 ✅
```

## 2. 로그인 화면

- **탭 토글**: 로그인 / 회원가입
- **이메일 + 비밀번호** (visibility 토글)
- **회원가입**: 닉네임 + 비밀번호 확인 + 실시간 일치 여부
- **간편 로그인**: 카카오/Google (비활성 상태로 표시, 추후 활성화)

## 3. 홈 화면

- 전체 진척도 바 (완료 절 / 31,103)
- 구약(39권) + 신약(27권) 카드 그리드 (4열)
- 카드 색상: 미시작=회색 · 진행중=연골드 · 완료=골드
- 실제 Supabase 진척도 반영

## 4. 절 작성 화면

### 기본값
- 진입 시 **타이핑 모드** 기본 선택

### 절 네비게이션
- 모든 절 번호를 **flexWrap 그리드**로 표시
- 완료된 절: ✓ 표시 + 골드 배경
- 현재 절: 브랜드 골드 원

### 완료 UX
| 상황 | 동작 |
|------|------|
| 절 완료 (장 미완) | 하단 토스트 → 1.8초 후 자동 다음 절 |
| 장 전체 완료 | 팝업 카드 (목록으로 / n장으로) |

### 모드 탭 아이콘 (Material Icons)
- 타이핑: `edit`
- 사진: `photo_camera`
- 음성: `mic`
- 문지르기: `swipe`

## 5. 언어 전환 (한글 ↔ ENG)

- 절마다 독립 선택
- 전환 시 볼스라이프 API에서 해당 언어 버전 로드
- 완료 처리는 언어 무관하게 동일

## 7. 상태 관리

| 항목 | 방식 |
|------|------|
| 인증 | `hooks/useAuth.ts` (Supabase onAuthStateChange) |
| 전체 진척도 | `hooks/useProgress.ts → useAllProgress()` |
| 책 진척도 | `hooks/useProgress.ts → useBookProgress()` |
| 장 진척도 | `hooks/useProgress.ts → useChapterProgress()` |
| 성경 텍스트 | `lib/bibleService.ts` (bolls.life + AsyncStorage 캐싱) |
